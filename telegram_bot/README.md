# 🚀 ربات تلگرام دانلودر همه‌کاره | All-in-One Telegram Media Downloader Bot

یک ربات تلگرام **فوق‌حرفه‌ای، سریع و پایدار** برای دانلود موزیک و ویدیو از تقریباً
همه‌ی پلتفرم‌ها — با رابط کاربری **کاملاً فارسی**، دکمه‌های شیشه‌ای، جستجوی آهنگ،
دیتابیس، پنل مدیریت، کش هوشمند، تنظیمات شخصی و پشتیبانی کامل از گروه.

A professional, fully-Persian Telegram bot to download audio & video from
1000+ sites — with glassy inline menus, music search, SQLite persistence,
an admin panel, smart caching, per-user settings and full group support.

---

## ✨ امکانات | Features

**📥 دانلود از همه جا (موتور `yt-dlp` + `spotdl`):**
- ▶️ **YouTube** — ویدیو با انتخاب کیفیت (144p تا 1080p) یا فقط صدا (MP3)
- 📸 **Instagram** · 🎵 **TikTok** (بدون واترمارک) · 🎧 **Spotify**
- ☁️ **SoundCloud** · 🐦 **X/Twitter** · 📘 **Facebook** · 🎮 **Twitch** · 🎬 **Vimeo** · 👽 **Reddit**
- 🔞 سایت‌های بزرگسال و **+۱۰۰۰ سایت دیگر**

**🎛 امکانات حرفه‌ای:**
- 🪟 **منوهای شیشه‌ای** کامل (منوی اصلی، تنظیمات، مدیریت)
- 🔎 **جستجوی آهنگ** با `/find` و `/music`
- 📊 **نوار پیشرفت زنده** هنگام دانلود (درصد، سرعت، زمان باقی‌مانده)
- ⚡️ **کش هوشمند** — فایل‌های قبلاً دانلودشده فوری ارسال می‌شوند (با `file_id`)
- ⚙️ **تنظیمات شخصی** — کیفیت پیش‌فرض ویدیو/صدا برای هر کاربر (در دیتابیس)
- 👥 **پشتیبانی کامل از گروه** + دکمه‌ی «افزودن به گروه»
- 🔒 **عضویت اجباری کانال** (اختیاری) — قفل اسپانسری
- 🪫 **محدودیت روزانه** قابل تنظیم برای هر کاربر
- 🛠 **پنل مدیریت** — آمار زنده، پیام همگانی، بن/آنبن کاربر
- 🛡️ مدیریت کامل خطا با پیام‌های فارسی، بدون کرش

## ⚡️ نصب سریع | Quick Start

### پیش‌نیازها
- Python **3.10+**
- **ffmpeg** نصب‌شده روی سیستم (برای استخراج صدا و ادغام ویدیو)

```bash
cd telegram_bot

python -m venv .venv
source .venv/bin/activate          # ویندوز: .venv\Scripts\activate
pip install -r requirements.txt

cp .env.example .env
#  فایل .env را باز کن و BOT_TOKEN را از @BotFather بگذار

python run.py
```

نصب ffmpeg:
```bash
sudo apt install ffmpeg      # Debian/Ubuntu
brew install ffmpeg          # macOS
choco install ffmpeg         # Windows
```

## 🎮 راهنمای استفاده | Usage

### دستورهای کاربری
| دستور | کار |
|------|-----|
| `/start` | شروع و منوی اصلی |
| `/find <عبارت>` | 🔎 جستجوی یوتیوب و نمایش نتایج |
| `/music <عبارت>` | 🎵 جستجو و دانلود مستقیم MP3 |
| `/dl <لینک>` | 📎 دانلود از یک لینک مشخص |
| `/settings` | ⚙️ تنظیمات شخصی |
| `/stats` | 📊 آمار دانلودهای تو |
| `/help` | 📖 راهنما |

> 🎯 **ساده‌ترین روش:** فقط **لینک** را بفرست! ربات خودش تشخیص می‌دهد و دکمه‌های
> دانلود (🎵 موزیک / 🎬 ویدیو / 📺 انتخاب کیفیت) را نشان می‌دهد.

### دستورهای مدیریت (فقط ادمین)
| دستور | کار |
|------|-----|
| `/admin` | 🛠 پنل مدیریت با آمار زنده |
| `/broadcast` | 📢 پیام همگانی به همه‌ی کاربرها |
| `/ban <user_id>` | 🚫 مسدود کردن کاربر |
| `/unban <user_id>` | ✅ رفع مسدودیت |
| `/cancel` | لغو عملیات در جریان (مثل پیام همگانی) |

### استفاده در گروه 👥
ربات را به گروه اضافه کن (یا دکمه‌ی «➕ افزودن به گروه» در منوی اصلی). بعد از آن
هر کسی لینک بفرستد یا از `/dl لینک` استفاده کند، برایش دانلود می‌شود.

## ⚙️ پیکربندی | Configuration (`.env`)

| متغیر | توضیح |
|------|------|
| `BOT_TOKEN` | **(الزامی)** توکن از @BotFather |
| `ADMINS` | شناسه‌های عددی ادمین‌ها (با کاما) |
| `ALLOWED_USERS` | فقط این کاربران اجازه دارند (خالی = عمومی) |
| `MAX_FILESIZE_MB` | حداکثر حجم ارسال (پیش‌فرض 49) |
| `SEARCH_RESULTS` | تعداد نتایج جستجو |
| `DAILY_QUOTA` | سقف دانلود روزانه‌ی هر کاربر (`0` = نامحدود) |
| `FORCE_JOIN_CHANNELS` | کانال‌های عضویت اجباری، مثل `@ch1,@ch2` |
| `DOWNLOAD_DIR` | پوشه‌ی موقت دانلود |
| `DB_PATH` | مسیر فایل دیتابیس SQLite |
| `COOKIES_FILE` | فایل کوکی برای محتوای نیازمند لاگین/سن |
| `PROXY` | پروکسی برای مناطق محدود (`socks5://...`) |
| `BASE_URL` / `BASE_FILE_URL` | برای Local Bot API Server (حجم تا 2GB) |

> **عضویت اجباری:** برای اینکه ربات بتواند عضویت کاربر را بررسی کند، باید در آن
> کانال **ادمین** باشد. اگر دسترسی نداشته باشد، کاربر را قفل نمی‌کند (تا اشتباه
> تنظیماتی باعث قفل‌شدن همه نشود).

### حجم بالای ۵۰ مگابایت
تلگرام برای ربات‌ها سقف ۵۰MB دارد. برای ارسال فایل‌های بزرگ‌تر (تا 2GB) یک
[Local Bot API Server](https://github.com/tdlib/telegram-bot-api) راه بیندازید و
`BASE_URL` و `BASE_FILE_URL` را تنظیم کنید.

## 🗂️ ساختار پروژه

```
telegram_bot/
├─ run.py                  # نقطه ورود
├─ requirements.txt
├─ Dockerfile / docker-compose.yml
├─ .env.example
└─ mediabot/
   ├─ bot.py               # ساخت اپلیکیشن، ثبت هندلرها، اتصال دیتابیس
   ├─ config.py            # خواندن تنظیمات از .env
   ├─ database.py          # SQLite: کاربران، آمار، تنظیمات، کش، بن
   ├─ downloader.py        # موتور yt-dlp + spotdl (async) + نوار پیشرفت
   ├─ handlers.py          # دستورها، تشخیص لینک، منوها، کال‌بک‌ها
   ├─ admin.py             # پنل مدیریت، پیام همگانی، بن/آنبن
   ├─ keyboards.py         # دکمه‌های شیشه‌ای
   ├─ store.py             # نگه‌داری موقت توکن‌ها (TTL)
   ├─ texts.py             # متن‌های رابط کاربری (فارسی)
   └─ utils.py             # توابع کمکی (نوار پیشرفت، فرمت‌ها)
```
