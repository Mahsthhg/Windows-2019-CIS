# ربات فروش کانفیگ VPN

ربات تلگرام دو قسمتی برای فروش کانفیگ VLESS — ربات مشتری + ربات ادمین.

## ساختار پروژه

```
vpn_bot/
├── main.py          ← نقطه شروع (هر دو ربات را اجرا می‌کند)
├── config.py        ← تنظیمات (توکن، قیمت، کارت)
├── database.py      ← دیتابیس SQLite
├── keyboards.py     ← کیبوردهای ربات
├── guides.py        ← راهنمای نصب برای پلتفرم‌های مختلف
├── customer_bot.py  ← ربات مشتری
├── admin_bot.py     ← ربات ادمین
├── requirements.txt
└── .env.example     ← نمونه فایل تنظیمات
```

## نصب و راه‌اندازی

### ۱. نصب وابستگی‌ها
```bash
pip install -r requirements.txt
```

### ۲. ساخت دو ربات جدید
- به @BotFather در تلگرام پیام بدید
- دو بار `/newbot` بزنید و دو ربات بسازید:
  - **ربات مشتری**: برای خریداران
  - **ربات ادمین**: فقط برای شما

### ۳. پیدا کردن آیدی ادمین
- به @userinfobot پیام بدید
- عدد `Id` را کپی کنید

### ۴. تنظیم فایل .env
```bash
cp .env.example .env
nano .env
```
مقادیر را پر کنید.

### ۵. اجرا
```bash
python main.py
```

## قابلیت‌های ربات مشتری

| قابلیت | توضیح |
|--------|-------|
| 🛒 خرید کانفیگ | انتخاب حجم، نمایش قیمت، دریافت رسید |
| 📦 سفارشات من | لیست سفارشات با وضعیت |
| 📚 راهنمای نصب | iOS، Android، Windows، Mac |
| 💬 پشتیبانی | ارسال تیکت به ادمین |
| 🎁 کد تخفیف | وارد کردن کد برای تخفیف |

## قابلیت‌های ربات ادمین

| قابلیت | توضیح |
|--------|-------|
| سفارش جدید | دریافت نوتیفیکیشن با رسید + دکمه تایید/رد |
| ارسال کانفیگ | بعد از تایید، کانفیگ + Sub لینک را ارسال کنید |
| 📊 آمار | تعداد کاربر، سفارش، درآمد |
| 📢 پیام همگانی | ارسال به همه کاربران |
| 💬 تیکت‌ها | پاسخ به تیکت‌های پشتیبانی |
| 🎫 کد تخفیف | ساخت کد تخفیف |
| 🚫 مسدودسازی | `/block USER_ID` و `/unblock USER_ID` |

## دستورات ادمین

```
/reply_ID متن پاسخ   ← پاسخ به تیکت پشتیبانی
/block 123456        ← مسدود کردن کاربر
/unblock 123456      ← رفع مسدودیت
/cancel              ← لغو عملیات جاری
```

## جریان خرید (فلوچارت)

```
مشتری → خرید کانفیگ → انتخاب حجم → تایید سفارش
     ↓
     نمایش شماره کارت + مبلغ
     ↓
     ارسال عکس رسید توسط مشتری
     ↓
     ادمین نوتیفیکیشن دریافت می‌کند (رسید + دکمه‌ها)
     ↓
     ادمین تایید می‌زند → ربات می‌خواهد کانفیگ بفرستد
     ↓
     ادمین کانفیگ VLESS را می‌فرستد
     ↓
     ادمین لینک Sub را می‌فرستد (یا - برای خالی)
     ↓
     کانفیگ + Sub + راهنما برای مشتری ارسال می‌شود ✅
```
